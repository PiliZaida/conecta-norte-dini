PUBLICACIÓN EN GITHUB
1. Descomprimir el ZIP en el computador.
2. Subir los archivos sueltos de la carpeta a la RAÍZ del repositorio.
3. GitHub > Add file > Upload files > Commit changes. Sobrescribir archivos existentes.
4. En Render, esperar a estado Live y recargar la página con Ctrl+F5.
5. NO subir los documentos de pauta ni resolución detallada al servidor estudiantil.
6. NO añadir la base de datos SQLite local ni archivos de prueba al repositorio.

POR VALIDAR CON UNA ENTREGA REAL
- Calidad de colocación de las respuestas en las tablas del documento.
- Legibilidad de respuestas largas: si un texto no cabe, el servidor pide acortarlo;
  no lo corta silenciosamente ni agrega hojas.
- Fluidez y pertinencia de DINI con Gemini usando la configuración ya publicada en Render.
- Participación de un compañero/a auténtico en el cuadro de evaluación de par.
